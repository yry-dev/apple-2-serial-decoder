🍎 Apple II GS Serial Decoder - Embed Examples

📋 How to Use Query String Parameters

You can now embed this tool with custom owner databases by passing a URL via the owners query parameter.

🔗 Example URLs:

With custom owners database:
https://your-domain.com/index.html?owners=https://example.com/owners.json
With custom mount point:
https://your-domain.com/index.html?mount=%23my-custom-div
Without owners database (owner info hidden):
https://your-domain.com/index.html

📝 Embed Code Examples:

1. With Custom Owners Database:

<iframe src="https://your-domain.com/index.html?owners=https://example.com/owners.json" width="100%" height="800px" frameborder="0"> </iframe>

2. With Custom Mount Point (Script Tag):

<div id="my-custom-div"></div> <script src="https://your-domain.com/app.iife.js" data-mount="#my-custom-div"></script>

3. With Custom Mount Point (Query String):

<div id="my-custom-div"></div> <script src="https://your-domain.com/app.iife.js"></script> <script> // The app will look for ?mount=%23my-custom-div in the URL </script>

4. Without Owners Database:

<iframe src="https://your-domain.com/index.html" width="100%" height="800px" frameborder="0"> </iframe>

🔧 Technical Details

  • Query Parameter: owners
  • Value: Full URL to your JSON file (must be publicly accessible)
  • Fallback: If no URL is provided, owner information is hidden
  • Error Handling: If the URL fails to load, owner info is gracefully hidden

📊 Expected JSON Format:

{ "E749": { "lastOwner": "John Smith", "ownerInfo": "Registered in 1987, last updated 2020" }, "CK823": { "lastOwner": "Jane Doe", "ownerInfo": "Registered in 1988, last updated 2019" } }

🎯 Mount Point Configuration

The app automatically finds the best mount point using this priority order:

  1. Query String: ?mount=%23my-div (URL encoded)
  2. Script Data Attribute: data-mount="#my-div"
  3. Element Data Attribute: <div class="apple2gs-decoder" data-mount="#my-div">
  4. Default Fallback: #app

Note: When using query strings, remember to URL encode the # symbol as %23.

🚀 Benefits of This Approach

  • Flexible: Use your own owner database or none at all
  • Embeddable: Perfect for embedding in other websites
  • Maintainable: Update owner data without touching the tool code
  • Scalable: Handle thousands of serial numbers
  • Privacy: Keep sensitive owner data on your own servers
